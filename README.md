# Aurelian Estates

A luxury real estate digital experience featuring an ultra-smooth 192-frame canvas scroll animation, interactive project portfolio, and responsive modern aesthetics.

## Features
- **Canvas Scroll Animation**: High-performance interactive visual sequence.
- **Projects Portfolio**: Filterable luxury properties with interactive modal specifications.
- **Brand & Heritage**: Dedicated legacy page detailing founding origins and philosophy.
- **Responsive Architecture**: Fully optimized mobile flex layout and sleek dark luxury aesthetic.

## Local Development
Open any modern browser or run:
```bash
python3 -m http.server 8080
```
Then navigate to `http://localhost:8080/`.
